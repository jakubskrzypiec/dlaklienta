# Spacer 3D — 21project / pokaz dla klientów

Minimalna demonstracja przewijanego spaceru 3D i końcowego hero z projektu Dobry Układ. **Nie zawiera pozostałych sekcji i podstron klientki.**

Kod JS i CSS jest przechowywany w tym repozytorium, natomiast ciężkie materiały źródłowe (721 klatek WebP na dwa profile, pakiety binarne, zdjęcia i logotyp) są pobierane z publicznego repozytorium `jakubskrzypiec/dobryuklad`, w wersji przypiętej do commita `7c0ef7b`. Dzięki temu nie powielamy ~80+ MB plików.

Demo pokazuje aktualną technologię i przykładowe wnętrze innego projektu. Każde indywidualne wdrożenie dla klienta wymaga uzgodnienia jego materiałów i dostosowania. Demo nie jest niezależną kopią wszystkich zasobów.

Repozytorium publikuje katalog `site/` przez GitHub Pages:
`https://jakubskrzypiec.github.io/dlaklienta/`.
